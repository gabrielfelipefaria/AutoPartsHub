Informações do Projeto

O AutoParts Hub é uma aplicação web acadêmica voltada à consulta de veículos por meio da API FIPE.

Categoria Sistema Web Interativo
Tecnologias HTML, CSS, JavaScript, Bootstrap e API REST
Foco UX, IHC, responsividade e dados dinâmicos

Critérios Atendidos

  • Múltiplas páginas conectadas
  • Consumo de API externa
  • Interface responsiva
  • Aplicação de UX e IHC
  • Feedback ao usuário
