# 🚗 AutoParts Hub

Sistema web desenvolvido para consulta inteligente de veículos utilizando a API FIPE.

## 📌 Sobre o Projeto

O AutoParts Hub é uma aplicação web responsiva que permite consultar informações de veículos por meio da API FIPE, proporcionando uma experiência intuitiva para pesquisa de marcas, modelos, anos e valores de mercado.

O sistema foi desenvolvido com foco em usabilidade, experiência do usuário (UX) e conceitos de Interação Humano-Computador (IHC), oferecendo uma interface moderna e de fácil navegação.

---

## 🎯 Objetivos

* Consultar veículos utilizando dados da API FIPE.
* Exibir informações detalhadas de marcas, modelos e anos.
* Permitir o armazenamento de veículos favoritos.
* Apresentar estatísticas de uso através de dashboard.
* Aplicar conceitos de UX e IHC.
* Desenvolver uma interface responsiva e intuitiva.

## 🚀 Funcionalidades

### Home

* Apresentação do sistema.
* Categorias de veículos.
* Veículos em destaque.

### Veículos

* Consulta dinâmica via API FIPE.
* Seleção de marca, modelo e ano.
* Exibição de informações detalhadas.

### Marcas

* Listagem de marcas disponíveis.
* Busca em tempo real.

### Favoritos

* Armazenamento local utilizando LocalStorage.
* Remoção individual ou total dos favoritos.

### Dashboard

* Estatísticas de consultas.
* Gráficos utilizando Chart.js.
* Indicadores de uso.

### Contato

* Formulário com validação.
* Feedback visual ao usuário.
